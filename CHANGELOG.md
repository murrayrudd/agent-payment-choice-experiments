# Release history

## v0.2.0 — October 26, 2026

First public release of the replication materials for *Operator mandates and tradeoffs in AI agent payment choices*.

- Frozen instruments, archived responses, prespecified analyses, and development pretests and pilot.
- Exploratory timing and monetary analyses, including all 6,000 bootstrap fits.
- Offline reproduction scripts, CSV exports, Figure 1, and source preservation records.
- GitHub workflow for integrity and replication checks.

The manuscript will be available on SSRN. Its DOI will be added when assigned. No manuscript file or private account administration files are included.
